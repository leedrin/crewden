# v2.10 — Self-Evolution

> **给 Claude Code / Codex 的执行指令：** 实现本文档描述的 v2.10。按 TDD 工作：先写失败测试，再实现，再跑测试确认通过。完成后运行 `pnpm verify`。

## 背景

v2.8 建立了 Knowledge Layer，v2.9 建立了 Trace 系统（含每一次 Task 的 Run history 数据）。v2.10 利用这些数据实现轻量自进化——从成功的 Task 中提取可复用的 Skill，从失败的 Task 中提取教训（依赖 v2.9 Trace 中的 Run 记录和 outcome），并维护知识库的卫生。

## 目标

- Skill capture：Task done（Review approved）→ 提取可复用模式 → Skill 草稿
- Improvement note：Task 失败后重试成功 → "下次遇到 X 先做 Y" → learning
- Knowledge hygiene：定期扫描 stale / conflict 并通知
- 不引入独立 Curator Agent——嵌入到 Task 闭环中

## 实现任务

### Task 1：Task → Skill Capture

Task done（Review approved）+ type = 'feature'/'bug'/'chore' + latestRun.summary 有价值时：

```typescript
async function captureSkillFromTask(task: TaskV2): Promise<KnowledgeEntry> {
  // 1. 提取执行模式
  const steps = task.latestRun?.metadata?.steps || [];
  const tools = task.latestRun?.toolCalls?.map(t => t.toolName) || [];
  const files = task.latestRun?.metadata?.changedFiles || [];

  // 2. 生成 Skill 草稿
  return createKnowledgeEntry({
    kind: 'artifact',
    scope: 'workspace',
    title: `[Draft] Pattern: ${task.title.split(' ').slice(0, 3).join(' ')}`,
    summary: task.latestRun.summary,
    body: `## Steps\n${steps.map(s => `- ${s}`).join('\n')}\n\n## Tools Used\n${tools.join(', ')}\n\n## Files\n${files.join(', ')}`,
    tags: [task.type, ...(task.owner?.role ? [task.owner.role] : [])],
    source_refs: [task.id, task.prUrl].filter(Boolean),
    skill_status: 'draft',
    applicable_roles: [task.owner?.role].filter(Boolean),
  });
}
```

只生成 draft，需要 Human 确认后才 verified。

### Task 2：Task → Improvement Note

Task 失败后重试成功时（latestRun.outcome='completed' + 之前有 failed Run）：

```typescript
async function captureImprovementNote(task: TaskV2): Promise<KnowledgeEntry> {
  const failedRun = task.runs.find(r => r.outcome === 'failed');
  const successfulRun = task.runs.find(r => r.outcome === 'completed');

  return createKnowledgeEntry({
    kind: 'learning',
    scope: 'workspace',
    title: `[Auto] Improvement: ${task.title}`,
    summary: `Task required ${task.runs.length} attempts to complete.`,
    body: `## Failure\n${failedRun?.error || 'Unknown error'}\n\n## Solution\n${successfulRun?.summary || 'Unknown solution'}`,
    tags: ['improvement', task.type],
    source_refs: [task.id],
    status: 'active',
  });
}
```
