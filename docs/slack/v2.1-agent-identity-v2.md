# v2.1 — Agent Identity v2

> **给 Claude Code / Codex 的执行指令：** 实现本文档描述的 v2.1。按 TDD 工作：先写失败测试，再实现，再跑测试确认通过。完成后运行 `pnpm verify`。

## 背景

v2.0 统一了 Polymorphic Actor 模型和 Task 状态机。v2.1 让 Agent 拥有真正的身份——不只是 profile 中的名字和描述，而是**角色、职责、能力标签、权限边界**。系统需要能回答：

- 这个 Agent 是什么角色？（Product / Architect / Developer / QA？）
- 它擅长什么？（capabilities: coding, review, testing？）
- 它能做什么？不能做什么？（permissions 硬约束）
- 什么情况下应该找它？（resolve 匹配引擎）

## 目标

- Agent Profile 扩展：role, responsibilities, capabilities, workingStyle, handoffPreference, constraints
- Agent 权限模型：permissions 硬约束，API 层强制执行
- Agent 匹配引擎：按 role/capability/负载 resolve 合适的 Agent
- Agent 不能修改自己的权限和角色（人才能管理 Agent）

## 非目标

- 不做组织架构图、部门、汇报线。
- 不做复杂 RBAC 系统，权限是 per-agent 配置。
- 不做自动负载调度（v2.4 Orchestrator 处理）。

```sql
-- 权限表（per-agent 硬约束）
CREATE TABLE IF NOT EXISTS agent_permissions (
  agent_id TEXT PRIMARY KEY,
  read_channels TEXT,          -- JSON array：可读 channel id 列表，空 = 全部
  write_channels TEXT,         -- JSON array：可写 channel id 列表，空 = 全部
  create_docs INTEGER NOT NULL DEFAULT 0,
  create_tasks INTEGER NOT NULL DEFAULT 1,
  claim_tasks INTEGER NOT NULL DEFAULT 1,
  create_branches INTEGER NOT NULL DEFAULT 0,
  create_prs INTEGER NOT NULL DEFAULT 0,
  merge_to_main INTEGER NOT NULL DEFAULT 0,
  deploy_to_prod INTEGER NOT NULL DEFAULT 0,
  access_sensitive_data INTEGER NOT NULL DEFAULT 0,
  call_external_apis TEXT,     -- JSON array
  max_context_tokens INTEGER NOT NULL DEFAULT 100000,
  requires_approval_for TEXT   -- JSON array
);
```

### Task 3：Agent 权限强制执行

在 API 中间件或 handler 层增加权限检查：

```typescript
// 中间件：权限检查
async function enforceAgentPermission(
  agentToken: string,
  requiredPermission: keyof AgentPermissions
): Promise<void> {
  const agent = await getAgentByToken(agentToken);
  const permissions = await getAgentPermissions(agent.id);
  if (!permissions || !permissions[requiredPermission]) {
    throw new HTTPException(403, `Agent does not have permission: ${requiredPermission}`);
  }
}

// 在以下操作前检查权限：
// - POST /api/tasks（create_tasks）
// - POST /api/tasks/:id/claim（claim_tasks）
// - POST /api/channels/:id/messages（write_channels 包含该 channel）
// - POST /api/knowledge（create_docs）
```

**测试**：`packages/server/test/permissions.test.ts`

- Agent 没有 create_tasks 权限时创建 task 返回 403
- Agent 不在 write_channels 白名单中时发消息返回 403
- Agent merge_to_main=false 时调用 merge 返回 403
