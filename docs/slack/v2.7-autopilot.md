# v2.7 — Autopilot Engine

> **给 Claude Code / Codex 的执行指令：** 实现本文档描述的 v2.7。按 TDD 工作：先写失败测试，再实现，再跑测试确认通过。完成后运行 `pnpm verify`。

## 背景

Agent 当前的触发方式是被动的——人等 Agent 或 Agent 检查 inbox。v2.7 引入 Autopilot，让系统能按规则自动触发 Agent 工作。

## 目标

- Autopilot 引擎：Schedule / Webhook / Event 三种触发方式
- 两种执行模式：create_task（创建 Task 到看板）/ send_message（发消息到 Channel）
- 并发策略：skip / queue / replace
- 4 个内置模板：Bug Triage / PR Review Reminder / Weekly Report / Security Scan

## 数据模型

```sql
CREATE TABLE IF NOT EXISTS autopilots (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  assignee_type TEXT NOT NULL,     -- agent | role
  assignee_id TEXT NOT NULL,
  execution_mode TEXT NOT NULL,    -- create_task | send_message
  task_template TEXT,              -- JSON: title template, body, priority, channelId
  concurrency_policy TEXT NOT NULL DEFAULT 'skip',
  enabled INTEGER NOT NULL DEFAULT 1,
  last_run_at INTEGER,
  next_run_at INTEGER,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS autopilot_triggers (
  id TEXT PRIMARY KEY,
  autopilot_id TEXT NOT NULL,
  kind TEXT NOT NULL,              -- schedule | webhook | event
  cron_expression TEXT,
  timezone TEXT DEFAULT 'UTC',
  webhook_url TEXT,
  webhook_secret TEXT,
  event_type TEXT,
  event_filter TEXT,               -- JSON
  created_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS autopilot_runs (
  id TEXT PRIMARY KEY,
  autopilot_id TEXT NOT NULL,
  trigger_id TEXT,
  status TEXT NOT NULL,            -- pending | running | completed | failed | skipped
  source TEXT,
  triggered_at INTEGER NOT NULL,
  completed_at INTEGER,
  result_task_id TEXT,
  error TEXT
);
```

### Task 5：Dispatch 逻辑

```typescript
async function dispatchAutopilot(autopilot, trigger, source): Promise<void> {
  // 1. 并发策略检查
  if (autopilot.concurrencyPolicy === 'skip' && hasActiveRun(autopilot.id)) {
    recordRun('skipped', 'previous run still active');
    return;
  }
  if (autopilot.concurrencyPolicy === 'replace') {
    cancelActiveRun(autopilot.id);
  }

  // 2. 解析 assignee
  let agentId: string;
  if (autopilot.assigneeType === 'agent') {
    agentId = autopilot.assigneeId;
  } else {
    const candidates = resolveAgents({ role: autopilot.assigneeId, mustBeIdle: false });
    agentId = candidates[0]?.agent.id;
  }
  if (!agentId) { recordRun('failed', 'no suitable agent'); return; }

  // 3. 执行模式
  if (autopilot.executionMode === 'create_task') {
    const task = await createTaskFromTemplate(autopilot.taskTemplate, agentId);
    recordRun('completed', task.id);
  } else if (autopilot.executionMode === 'send_message') {
    await sendMessage(autopilot.taskTemplate.channelId, agentId, autopilot.taskTemplate.title);
    recordRun('completed');
  }
}
```
