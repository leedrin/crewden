# v2.9 — Full Trace & Audit

> **给 Claude Code / Codex 的执行指令：** 实现本文档描述的 v2.9。按 TDD 工作：先写失败测试，再实现，再跑测试确认通过。完成后运行 `pnpm verify`。

## 背景

v2.0 引入了基础 audit log。v2.9 将其升级为完整的 Trace 系统——每次 Task 从创建到完成形成 span-based 全链路记录，可追溯、可筛选、可回放。

## 目标

- Span-based Trace：traceId → spanId → parentSpanId 树状结构
- 核心 eventType 全覆盖：task 生命周期 + context generation + plan + tool call + review + approval
- 统一 Activity Feed：Trace event + audit log + message 混合展示
- 敏感字段自动 redaction
- 可查询：按 taskId / agentId / eventType / 时间范围

## 数据模型

```sql
CREATE TABLE IF NOT EXISTS traces (
  id TEXT PRIMARY KEY,
  trace_id TEXT NOT NULL,         -- 一次完整任务
  span_id TEXT NOT NULL,          -- 一个步骤
  parent_span_id TEXT,            -- 父步骤
  task_id TEXT NOT NULL,
  event_type TEXT NOT NULL,
  -- task_created | task_assigned | context_package_generated | plan_generated |
  -- plan_approved | approval_granted | tool_call | tool_result | file_modified |
  -- file_created | test_run | test_result | pr_created | review_submitted |
  -- task_completed | error
  actor_type TEXT NOT NULL,
  actor_id TEXT NOT NULL,
  detail TEXT,                    -- JSON（敏感字段 redacted）
  timestamp INTEGER NOT NULL,
  duration_ms INTEGER
);

CREATE INDEX idx_traces_trace ON traces(trace_id, timestamp);
CREATE INDEX idx_traces_task ON traces(task_id);
CREATE INDEX idx_traces_actor ON traces(actor_type, actor_id);
CREATE INDEX idx_traces_event ON traces(event_type);
```

## 实现任务

### Task 1：Trace 表 + 写入 Hook

在 task 生命周期关键节点写入 trace：

- Task 创建/分配/状态变更
- Context Package 生成
- Plan 生成/审批
- Approval 请求/响应
- Tool Call 发起/完成
- PR 创建/合并
- Review 请求/响应
- Task 完成
