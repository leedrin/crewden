# v2.6 — Code Execution & Review

> **给 Claude Code / Codex 的执行指令：** 实现本文档描述的 v2.6。按 TDD 工作：先写失败测试，再实现，再跑测试确认通过。完成后运行 `pnpm verify`。

## 背景

v2.5 之前，Agent 只能在频道中讨论和创建文档/任务。v2.6 让 Agent 真正开始执行编码工作——通过 Git 集成创建分支、修改代码、创建 PR，并走完整的分层 Review 流程。

## 目标

- Git 集成：Agent 可以 create branch、commit、create PR
- PR 作为代码事实源：Agent 不能直接操作主干
- 分层 Review：Self Review → Review Agent → CI status read → Human Review → QA
- Task 完成条件：PR merged + CI status check passed（只读取外部 CI 状态，不接入管理 CI 平台）+ Review approved

## 非目标

- 不做 CI 平台集成（创建/管理 GitHub Actions、GitLab CI 等管道配置）——v2.6 只通过 PR status check API 读取已有 CI 运行结果作为 gate 条件
- 不做多仓库编排
- 不做自动 conflict 解决
- 不做 per-tool 权限门控（v2.1 agent_permissions 已做 API 级门控，per-tool 权限留到后续版本）

### Task 4：Task 完成条件

```typescript
// done 状态的准入条件
async function canTaskBeDone(task: TaskV2): Promise<boolean> {
  // 开发类任务（feature/bug）
  if (task.type === 'feature' || task.type === 'bug') {
    if (!task.prUrl) return false;
    if (task.prStatus !== 'merged') return false;
    if (!task.approvals.some(a => a.type === 'pr_merge' && a.status === 'approved')) return false;
    // 读取 PR 的 CI status checks（只读外部 CI 状态，不管理 CI 管道）
    const ciStatus = await readPRCIStatus(task.prUrl);
    if (!ciStatus.allChecksPassed) return false;
  }
  // 所有任务
  if (task.definitionOfDone?.length > 0) {
    const checklist = task.latestRun?.checklist || [];
    if (!checklist.every(c => c.checked)) return false;
  }
  return true;
}
```
