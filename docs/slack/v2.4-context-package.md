# v2.4 — Context Package Engine

> **给 Claude Code / Codex 的执行指令：** 实现本文档描述的 v2.4。按 TDD 工作：先写失败测试，再实现，再跑测试确认通过。完成后运行 `pnpm verify`。

## 背景

Agent 执行 Task 前的上下文通常是人工拼凑的——把所有相关频道消息、文档、代码一次性塞给 Agent。这导致：token 浪费、噪音过载、关键信息淹没。

v2.4 引入 **Context Package**——Task assigned 时，系统自动从多源检索并组装简练的上下文包，按优先级截断，确保不超过 Agent 的 maxContextTokens。

## 目标

- Task assigned → 自动生成 Context Package
- Context Package 来源：Task 本身 + 关联 Decision/Document + 来源 Thread 摘要 + 父 Task 交付物
- Context Budget 管理：按优先级截断，不超过 Agent.maxContextTokens
- Context Package 注入到 Agent 的 turn context

## 设计参考

> Context Package 生成引擎为 Crewden 原创设计，MultiCa 无 Context Budget 管理概念。设计原则（按优先级截断、不超过 Agent.maxContextTokens）来自行业最佳实践。

## project 影响（v2.2.1）

| 影响点 | 说明 |

| 检索范围 | Context Package 检索限定当前 project：Decision、Document、Thread 摘要只检索同 project 下的数据 |

## 数据模型

```typescript
interface ContextPackage {
  taskId: string;
  generatedAt: number;
  sections: ContextSection[];
  totalTokens: number;       // 估算值
  agentMaxTokens: number;    // Agent 的上下文预算
  truncationApplied: boolean; // 是否有内容被截断
}

interface ContextSection {
  priority: number;           // 1=最高（Task 定义），5=最低（背景文档）
  source: 'task' | 'decision' | 'document' | 'thread_summary' | 'parent_task_result' | 'code_path';
  title: string;
  content: string;            // 摘要内容（非全文）
  tokenEstimate: number;
}
```

## 实现任务

### Task 1：Context Package 构建引擎

新增 `packages/hub-core/src/contextPackageBuilder.ts`：

```typescript
async function buildContextPackage(task: TaskV2, agent: Agent): Promise<ContextPackage> {
  const sections: ContextSection[] = [];

  // P1: Task 定义（最高优先级）
  sections.push({
    priority: 1, source: 'task',
    title: `Task: ${task.title}`,
    content: formatTaskDefinition(task),
    tokenEstimate: estimateTokens(task.title + task.description + task.acceptanceCriteria),
  });

  // P2: 约束 + 验收标准 + DoD
  sections.push({
    priority: 2, source: 'task',
    title: 'Constraints & Acceptance Criteria',
    content: formatConstraints(task),
    tokenEstimate: estimateTokens(task.constraints + task.acceptanceCriteria + task.definitionOfDone),
  });

  // P3: 关联 Decision 摘要
  for (const decisionId of task.relevantDecisions || []) {
    const decision = await getDecision(decisionId);
    if (decision) {
      sections.push({
        priority: 3, source: 'decision',
        title: `Decision: ${decision.title}`,
        content: `Problem: ${decision.problem}\nDecision: ${decision.decision}\nRationale: ${decision.rationale}`,
        tokenEstimate: estimateTokens(decision.problem + decision.decision),
      });
    }
  }

  // P4: 来源 Thread 摘要（如果有）
  if (task.sourceThreadId) {
    const summary = await getThreadSummary(task.sourceThreadId);
    if (summary) {
      sections.push({
        priority: 4, source: 'thread_summary',
        title: `Thread Summary: ${summary.title}`,
        content: summary.content,
        tokenEstimate: estimateTokens(summary.content),
      });
    }
  }

  // P5: 父 Task 交付物
  for (const parentId of task.dependsOn || []) {
    const parentTask = await getTask(parentId);
    if (parentTask?.latestRun?.summary) {
      sections.push({
        priority: 5, source: 'parent_task_result',
        title: `Parent Task Result: ${parentTask.title}`,
        content: parentTask.latestRun.summary,
        tokenEstimate: estimateTokens(parentTask.latestRun.summary),
      });
    }
  }

  // 按优先级排序
  sections.sort((a, b) => a.priority - b.priority);

  // Budget 检查 + 截断
  return applyTokenBudget(sections, agent.maxContextTokens);
}
```

- 超过 budget 时低优先级 section 被截断
- 空 Task（无 Decision/Thread/父Task）只包含 P1+P2
- 截断标记正确

### Task 3：Token 估算工具

```typescript
// 简易 token 估算（约 1 token ≈ 4 字符 for English, ≈ 2 字符 for CJK）
function estimateTokens(text: string | string[]): number {
  const content = Array.isArray(text) ? text.join(' ') : text;
  const englishChars = (content.match(/[a-zA-Z0-9\s]/g) || []).length;
  const cjkChars = (content.match(/[\u4e00-\u9fff]/g) || []).length;
  const otherChars = content.length - englishChars - cjkChars;
  return Math.ceil(englishChars / 4 + cjkChars / 2 + otherChars / 3);
}
```
