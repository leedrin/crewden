# v2.8 — Knowledge Layer

> **给 Claude Code / Codex 的执行指令：** 实现本文档描述的 v2.8。按 TDD 工作：先写失败测试，再实现，再跑测试确认通过。完成后运行 `pnpm verify`。

## 背景

v1.5 已经实现 Knowledge & Memory Layer，包含可检索的 knowledge entry、API、Agent-facing tools 和 Web Knowledge panel。v2.8 不是从零新建知识库，而是在现有 v1.5 knowledge layer 上升级：补充分层 scope、使用统计、Task 自动沉淀和 Context Package 检索增强，让 Agent 执行前能拿到更贴合任务的项目经验。

## 目标

- 升级现有 Knowledge Entry：增加分层存储（agent scope / workspace scope / global scope）
- 沿用 v1.5 kind：decision / project_archive / user_preference / runbook / learning / artifact
- Task done → 自动提取经验 → learning kind 草稿
- Project/Goal 完成 → 自动生成 project_archive
- 知识卫生：stale / conflict / archived 标记
- Agent 执行前检索相关知识

## 数据模型

```sql
-- v1.5 已有 knowledge_entries 表和 CRUD/search API。
-- v2.8 只做向后兼容扩展，不重建表、不丢弃既有 knowledge。
ALTER TABLE knowledge_entries ADD COLUMN scope TEXT NOT NULL DEFAULT 'workspace';
  -- agent | workspace | global

ALTER TABLE knowledge_entries ADD COLUMN usage_count INTEGER NOT NULL DEFAULT 0;
ALTER TABLE knowledge_entries ADD COLUMN last_used_at TEXT;

CREATE INDEX idx_knowledge_scope ON knowledge_entries(scope);
CREATE INDEX idx_knowledge_kind ON knowledge_entries(kind);
CREATE INDEX idx_knowledge_tags ON knowledge_entries(tags);
```
